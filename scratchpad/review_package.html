P0 코드리뷰 승인 이후, GPT가 지정한 P1 6개 항목을 순서대로 반영했습니다. 아래는 GPT 재검토용 요약입니다.

1SQLite 신규쓰기 중단 → PG 단일 원본

DONE

작업 상태의 이중 저장을 제거했습니다. 대시보드가 쓰던 SQLite 작업기록을 걷어내고, 모든 생성 job은 PostgreSQL generation_jobs만 읽고 씁니다. 비-PG(구식 파일) 병원만 메모리 fallback(_MEMJOB)으로 남겨 하위호환. 새 데이터는 전부 PG.

2런타임 ensure_* DDL 제거 방침

DONE

스키마 변경은 Alembic 마이그레이션(0002–0006)이 단일 경로. 앱 기동 시 테이블을 만드는 즉석 DDL에 의존하지 않으며, ensure_*는 개발/부트스트랩 편의용으로만 남아 운영 스키마의 근거는 마이그레이션입니다. 0002–0004 채택(adoption), 0005 프로비저닝 함수, 0006 자료 스냅샷 테이블.

3병원 slug → PG UUID 매핑

DONE

대시보드의 병원 slug를 PostgreSQL hospitals.id(UUID)로 해석하는 경로를 확립. 자료·job·대본이 전부 hospital_id 기준 RLS로 격리됩니다.

4새 병원 provisioning

DONE

병원 생성 시 PG에 병원 + 생성자 admin 멤버십 + 감사로그를 원자적으로 만듭니다. app_rw에 hospitals 직접 INSERT 권한을 주지 않고 SECURITY DEFINER 함수(소유자 NOLOGIN app_owner)로만 프로비저닝 — 권한 경계 유지. slug 중복은 기존 병원 반환(멱등). 이걸로 동료 업로드 실패의 근본원인(비-PG 병원의 임시디스크 소실)도 해소.

SELECT id FROM hospitals WHERE slug = p_slug;   -- 있으면 반환(멱등)
INSERT INTO hospitals(id,slug,name) VALUES(...);
INSERT INTO hospital_memberships(...) ;          -- 생성자
INSERT INTO membership_roles(...,'admin');       -- admin 부여
INSERT INTO audit_events(...,'hospital.provision');

5편집 라우트 대시보드 이전 · 1단계

DONE

대시보드가 소유하는 script-centric 진입점 /scripts/<병원>/<버전id>[/<섹션>]을 추가했습니다. 생성→편집 CTA가 이제 대시보드 주소를 가리키고, 현재는 스튜디오 렌더러로 전이 리다이렉트(evidence/images/approval 앵커 보존)합니다.

남은 후속(정직하게): 스튜디오 내부 로직을 공통 서비스로 추출하고 /studio를 완전히 은퇴시키는 앱 병합은 별도 리팩터로 남겼습니다. 별도 WSGI 앱 + RLS 테넌트 구조라 큰 변경이라, 안전하게 진입점부터 대시보드로 옮긴 상태입니다. 사용자 경험은 이미 단일 로그인·동일 디자인으로 통합돼 있습니다.

6CSRF · 역할권한 · 자료 스냅샷

6a

CSRF 보호. 세션당 토큰(session["_csrf"])을 발급하고 모든 상태변경 POST를 before_request에서 검증. 대시보드·스튜디오 양쪽 폼에 히든 토큰 주입.

6b

병원 내부 역할 게이트. membership_roles 기반으로 편집=editor/approver/admin, 검수=approver/admin, 이미지 재생성=editor 이상으로 제한(403).

6c

자료 version 스냅샷. 대본 생성 시점의 자료(파일명·체크섬·크기)를 generation_job_materials로 job에 결착 — 어떤 자료로 만든 대본인지 영구 기록(재현·책임소재).

INSERT INTO generation_job_materials
  (id,hospital_id,job_id,material_id,filename,checksum,size_bytes)
SELECT gen_random_uuid(), :h, :j, id, filename, checksum, size_bytes
FROM materials WHERE hospital_id = :h;   -- 생성 직후 스냅샷
