scripts FOR UPDATE → version_approval_states FOR UPDATE (편집·검수·승인 직렬화) + advisory lock(freeze 트리거와 공유).

inv2

current_version_id == target 아니면 P2015(VersionConflict). 상태 none/pending 아니면 P2013.

inv11

작성자==승인자면 차단(42501). 자기승인은 별도 경로만.

gate

claim별 최신 effective human_decision: accepted+verified / waived / not_applicable (레거시 automated verified 허용). 하나라도 미충족이면 23514.

app_rw

core는 app_rw 직접 실행 불가. wrapper만 EXECUTE.

4wrapper 4개

approve

fn_approve_version(mode=normal, 기존 signature 유지). 정상 승인.

self

fn_self_approve_version(creator==actor + allow_self_approval + admin + 사유, audit 'approval.self_approve').

reject

fn_reject_version(current·none/pending·사유→rejected).

revoke

fn_revoke_version(approved→revoked·admin·사유·비-current 과거승인도 허용).
