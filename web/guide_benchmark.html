유튜브 벤치마킹 사용 가이드

잘나가는 채널의 구성·화법은 배우되, 내용은 원장님의 논문·임상 경험으로 채웁니다. 아래 순서대로 직접 만들어 보실 수 있어요.

📎 가장 먼저 알아둘 것 이 벤치마킹은 병원에 업로드된 자료(원장 프로필·논문·기존 대본)를 자동으로 참고해 기획합니다. 경쟁 영상에서는 '형식(구성·화법)'만 배우고, 내용의 중심은 언제나 우리 자료와 원장님의 근거예요. 그래서 자료가 많을수록 기획이 정확해집니다.

무엇을 하는 기능인가요

📊

잘되는 영상 분석

같은 주제 인기 영상들이 왜 끝까지 보게 되는지(도입·구성·화법)를 뽑아냅니다.

🎯

우리만의 차별화

원장님 논문·임상 경험으로 경쟁 채널이 못 가진 각도를 잡습니다.

🛡️

표절 걱정 없이

완성 대본이 원본과 너무 닮지 않았는지 자동 검사합니다.

📄

의학적으로 안전

유튜브 주장은 사실로 쓰지 않고, 논문 근거만 대본에 담습니다.

직접 만드는 법 — 버튼 순서대로

파란 칸은 화면에서 누르는 버튼이에요. 순서대로 따라가면 됩니다.

▶

시작하기

벤치마킹 화면 열고 프로젝트 만들기

  1. 병원 대시보드에서 🔍 유튜브 벤치마킹 칸의 벤치마킹 열기 → 클릭.
  2. + 새 벤치마킹 프로젝트 에 제목 입력 예: 이명 벤치마킹 3편 → 만들기.
  3. 만든 프로젝트를 클릭해 상세 화면으로 들어갑니다. ①~④ 단계가 순서대로 보여요.
1

영상 등록 · 자막 · 분석

벤치마킹할 영상 넣고, 자막 확보, 분석

  1. 주제로 자동 찾기 (추천) — 주제 입력 후 🔎 인기 영상 자동 찾기. 조회수 높은 관련 영상을 1~5개 골라 자동 등록 + 조회수까지 채워줍니다. 예: "이명 치료"
  2. 또는 URL 직접 — 원하는 영상이 있으면 유튜브 주소를 붙여넣고 영상 추가.
  3. 자막 넣기 — 각 영상에서 자막을 붙여넣기 하거나 자막 파일(.srt/.vtt/.txt) 업로드 후 자막 저장. 되면 available 로 바뀌어요.
  4. 영상 분석 — 자막이 있는 영상에서 이 영상 분석 클릭 → ✅분석완료. 영상마다 한 번씩.
⚠️ 자막 팁 유튜브 자동 자막수집은 자주 실패해요. 안 되면 다글로 같은 데서 자막을 뽑아 파일로 올리거나 붙여넣으세요.
2

교차 종합 · 주장 정리

흥행 공식과 '우리만의 빈틈' 찾기

  1. 교차 종합 실행 — 분석한 영상들을 비교해 공통 흥행 공식 · 차별화 기회 · 복제 금지 표현을 정리해 보여줍니다.
  2. 검증 대상 주장 정리 — 영상들이 말한 의학 주장을 모읍니다. 전부 검증 전 상태(아직 사실 아님)로만 들어가요.
3

기획안 만들기 · 승인

경쟁 형식 + 우리 자료를 합쳐 설계

📎 우리 자료 반영 기획안은 경쟁 영상만 보는 게 아니라, 업로드한 원장님 프로필·논문·기존 대본을 함께 읽고 만들어요. 그래서 우리만의 근거로 차별화됩니다.
  1. 기획 방향 적기 (선택) — 기획 방향 칸에 원하는 주제·톤·각도를 편하게 적으면 그대로 최우선 반영해요. 예: "대표 시술 소개" · "대표 치료사례" · "가장 많이 신경쓰는 Top3 고민" · "원장 소개" · "계절 이슈" 비워도 됩니다.
  2. 기획안 생성 — 종합 결과 + 우리 자료 (+ 적은 방향)로 주제·차별화 각도·훅·구성 초안을 만듭니다.
  3. 내용을 열어보고 괜찮으면 승인, 아니면 반려. 승인해야 다음으로 넘어가요.
  4. 승인되면 생성 브리핑 보기가 생깁니다 — 대본 만들 때 참고할 요약이에요.
4

대본 제작 · 표절 검사

대본 만들고 원본과 안 겹치는지 확인

  1. 브리핑을 참고해 기존 대본 만들기 버튼으로 대본을 제작합니다.
  2. 완성 대본을 ④ 원본 유사도 검사 칸에 붙여넣고 유사도 검사.
  3. 결과가 낮음 이면 안전, 높음 이면 원본과 너무 겹치니 고쳐 쓰세요.

안심하셔도 되는 이유

✓

유튜브 주장을 사실로 쓰지 않습니다

배우는 건 '형식'뿐. 의학 사실은 원장님 논문 등 검증된 근거만 사용합니다.

✓

승인 없이는 진행되지 않습니다

기획안을 원장님이 확인·승인하셔야 대본 단계로 넘어갑니다.

✓

표절은 자동으로 걸러냅니다

완성 대본과 원본 영상의 유사도를 검사해 너무 닮은 부분을 미리 고칩니다.

✓

콘텐츠의 중심은 원장님입니다

원장님의 연구·임상 경험이 차별화의 핵심입니다. 남을 베끼는 게 아닙니다.

남의 채널을 따라 하는 게 아니라, 원장님을 가장 원장님답게.

궁금하신 점은 담당 매니저에게 편하게 말씀해 주세요.
