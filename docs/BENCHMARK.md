# 유튜브 벤치마킹 (Phase 1 · 링크 기반 MVP)

잘나가는 채널 영상을 등록·분석해 **흥행 공식**을 뽑고, 우리 **기획안**으로 이어가는 기능.
자료가 부족한 신규 광고주에 특히 유용. 진입: 병원 대시보드 → **🔍 유튜브 벤치마킹**.

## 사용 흐름 (`/h/<병원>/benchmark`)
1. **프로젝트 생성** — 예: "이명 벤치마킹 3편".
2. **영상 등록** — 유튜브 URL 붙여넣기(1~5개). `📊 메타데이터 가져오기`로 조회수·게시일·길이·캡션여부 수집(API 키 필요).
3. **자막 확보** — 붙여넣기 또는 SRT/VTT/TXT 업로드. `외부 자동수집 시도` 체크 시 youtube-transcript-api 시도(서버 IP 차단이 잦아 실패하면 수동 안내).
4. **영상 분석** — 영상별로 훅·구성·화법·흥행요소·(관찰된)의학주장·복제금지 표현 추출.
5. **교차 종합** — 여러 영상 공통 패턴·차별화 기회(gaps)·흥행 공식 종합.
6. **검증 대상 주장 정리** — 영상들이 말한 의학주장을 후보로 모음(전부 `pending_verification`).
7. **기획안 생성 → 승인** — 형식(구성·각도·훅) 설계. 승인자/관리자가 승인해야 다음 단계 가능.
8. **생성 브리핑** — 승인된 기획안 → 기존 대본 생성기에 넣을 브리핑. **생성 로직은 그대로**(의학 내용은 기존 근거검증을 따름).
9. **원본 유사도 검사** — 완성 대본을 붙여넣어 원본 자막과 축자/의미 겹침·표절 위험(low/medium/high) 확인.

## 안전 설계 (지침 준수)
- **지식 왜곡 방지**: 유튜브 자막·주장을 **evidence로 자동 승격하지 않음**. 의학 사실은 논문 근거검증(기존)만 통과해야 대본에 사용. 벤치마킹은 **형식(구성·화법)** 참고용.
- **표절 방지**: 채널 고유 표현은 "복제 금지"로 분리, 유사도 검사로 축자(연속 12단어+ = high) 감지.
- **승인 게이트**: 기획안은 `draft→approved`(승인자/관리자)만 생성에 사용. 기존 script 승인과 **분리된** 별도 게이트.
- **테넌트 격리**: 8개 테이블 전부 RLS FORCE(app_rw = hospital_id 일치). route는 service만 호출(직접 SQL·상태전이·RLS 우회 없음).
- **생성 무손상**: run.py/director.md 등 생성 파이프라인 코드 변경 0. 결과물 무영향.

## 비용 (LLM: 분석/종합/기획/유사도는 저렴모델 Sonnet $3/$15)
- 영상 분석 ≈ ₩40/편, 교차 종합 ≈ ₩50, 기획안 ≈ ₩40, 심층 유사도(선택) ≈ ₩65.
- **3편 프로젝트 1회 ≈ ₩200~350** (심층 유사도 포함 시 ~₩400). 축자 유사도만이면 유사도는 **무료**(결정론).
- YouTube Data API: 무료 quota(10,000 units/일)로 충분(videos/channels list 각 1 unit).
- ※ 실제 **대본 생성**(Opus 디렉터)은 별개이며 기존과 동일(~₩3~4k/편). 벤치마킹은 그 앞단 기획 비용.

## 관측
- 각 LLM 단계는 `[COST] stage=... usd=...` 로그 + `llm.cost.record()` 적재. provenance(model·prompt_version·content_hash) 전 artifact 기록.

## 활성화에 필요한 것
- **YouTube Data API 키**(`YOUTUBE_API_KEY`) — 없어도 URL·자막·분석·기획은 동작(메타만 생략). 키 넣으면 조회수 등 자동 수집.
- (선택) 외부 자막 성공률이 낮으면 다글로/자막파일 업로드로 운영.
