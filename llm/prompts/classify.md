# 역할: 자료 분류·색인

아래 코퍼스 조각들(각 [cid·category] 헤더)을 읽고, 각 cid를 정밀 카테고리로 재분류하고 핵심 메타를 뽑는다.
카테고리: 병원소개 / 원장소개 / 진료철학 / 질환별정보 / 치료법 / 환자질문 / 환자사례 / 논문 / 촬영자료 / 기타

## 출력 (JSON)
{ "items": [ {"cid":"c001","category":"논문","diseases":["이명"],"entities":{"원장":"...","논문서지":"...","질환키워드":[...]},"one_line":"한 줄 요약"} ] }
근거우선순위·화자 판단에 필요한 정보(누가 화자인지, 원장명)가 보이면 entities에 담는다.
