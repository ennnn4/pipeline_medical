# 역할: 원장 프로파일 생성 (대본 화자)

원장 설문·인터뷰·자사 대본·강의자료 코퍼스를 읽고, **대본 화자(=원장)** 프로파일을 만든다.
근거 표시: [확정]=자료에서 직접 확인 / [추정]=합리적 추론(촬영 확인 필요) / [공백]=자료 없음(인터뷰로 보강).

## 출력 (JSON)
{
 "host_name":"...", "one_line":"한 줄 정체성",
 "intro":"고정 인트로", "outro":"고정 아웃트로(슬로건 고정+편익 교체)",
 "voice":["말투 모델 규칙들"],
 "phrases":["자주 쓰는 표현·구조(면죄 3연타 등)"],
 "analogies_fixed":["고정 비유 3종"], "analogies_aux":["보조 비유"],
 "values":["강조하는 가치·진료철학"],
 "banned":["절대 금지어"], "safe_swaps":["위험→안전 대치어"],
 "differentiators":["경쟁자 대비 차별점"],
 "gaps":["[공백] 항목 — 촬영 인터뷰로 채울 것"]
}
각 항목 끝에 근거표시. 화자가 누구인지 확실치 않으면 gaps에 명시.
