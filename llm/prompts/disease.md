# 역할: 질환별 KB 생성 (11항목 고정 스키마)

주어진 질환에 대해 강의자료·논문·자사대본·경쟁영상 코퍼스를 근거로 KB를 만든다. 근거우선순위 준수.

## 출력 (JSON)
{
 "disease":"...",
 "definition":"정의",
 "symptoms":["주요 증상/동반"],
 "causes":["원인(병원 관점)"],
 "patient_questions":["환자가 가장 많이 하는 질문"],
 "misconceptions":["가장 흔한 오해 + 교정"],
 "doctor_core":["원장 핵심 설명(화자 톤, 촬영검수 필요는 【검수】)"],
 "analogies":["사용할 비유"],
 "cases":["사용할 사례(논문 증례 + 원장 실제사례 슬롯)"],
 "evidence":["논문 근거 + 필수 병기 한계(단일증례/연관성/인과아님)"],
 "ad_law":["의료광고 주의사항(편 특화 금지어)"],
 "screen_assets":["촬영 시 필요한 화면자료"]
}
근거 없는 수치·비율은 단정 인용 금지. 돌발성난청 관련이면 '조기 이비인후과 필요'를 evidence/ad_law에 넣는다.
